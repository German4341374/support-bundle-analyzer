# Roadmap

## 0.1 foundation

- Secure archive ingestion, deterministic workspaces, built-in log/HAR analysis and offline reports.
- Version 1 JSONL plugin protocol and independently tested polyglot analyzers.
- Local API, PostgreSQL schema and deployment validation.

## 0.2 integration

- Automatic plugin discovery, compatibility checks and orchestrated execution.
- Persistent API session repository, resumable jobs and explicit retention controls.
- Kubernetes, Docker, network and configuration-specific rule packs.

## 0.3 investigation workflow

- Cross-source correlation, clock-skew assistance, richer compare views and SARIF.
- Browser E2E tests and accessibility audits.
- Measured large-bundle and PostgreSQL query-plan reports.

## 1.0 criteria

- All supported analyzers integrated through the stable protocol.
- Clean-checkout verification across documented platforms.
- Signed release binaries, SBOMs, provenance and migration-tested server mode.
- Security review of archive, report, redaction and plugin boundaries.
