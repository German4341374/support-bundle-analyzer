# Good first issue candidates

Each task below is intentionally small enough for a focused pull request and must include synthetic fixtures and tests.

1. Add a parser fixture for an nginx combined-log line containing an IPv6 client address.
2. Add a Windows Event XML rule for a documented service stop event without claiming root cause.
3. Support one additional timezone-bearing timestamp format in the Python log plugin.
4. Add an adversarial TAR fixture with an overlong Unicode-normalized path.
5. Add a documentation example showing how to interpret a `completed_with_warnings` analyzer run.
6. Add a compatibility-matrix test for a PHP-FPM worker-exhaustion fixture.
7. Improve the static viewer keyboard focus style and add a DOM-level accessibility assertion.

Before starting, search open issues for duplicates. Do not attach real support data. The expected workflow and acceptance criteria are in [CONTRIBUTING.md](../../CONTRIBUTING.md).
